# Project Guidelines - SIDIA Automation Suite

## Codebase Intelligence & Mapping
Gunakan **Trail-Code** (https://github.com/trailhq/Trail-Code) untuk pemetaan setiap kode dengan fungsinya:
- Gunakan `trail` / Trail-Code MCP tools (`trail_find_code`, `trail_file_api`, `trail_trace_calls`, `trail_find_all`, `trail_repo_map`) untuk menelusuri hubungan antar fungsi, file API surface, dan pemanggil fungsi.
- Pertahankan struktur dan indeks pemetaan di direktori `.trail/`.
